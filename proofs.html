RUNSAFE · the mathematics

The proofs behind the RUNSAFE ladder rating

This page states the model, the construction and every theorem behind RUNSAFE's ladder rating, with complete proofs. The proofs use counting and induction only. Section 12 lists the independent checks and runs a checker in your browser.

Section 1

The release model

A knitting program makes loops one at a time. Each new loop is pulled through a set of loops that already exist: a knit pulls it through the loops held on a needle and replaces them; a split pulls it through them and keeps the old loops on the opposite bed; a tuck or cast-on makes a loop through nothing. The semantics follow the Knitout specification [1].

Definition 1 Capture graph. The loops of a program are the vertices. Write \(u \to v\) when loop \(v\) is made through loop \(u\): \(v\) holds \(u\). Every arrow points from an older loop to a newer one, so the graph has no cycles. The holders of \(u\) are its out-neighbours \(\operatorname{out}(u)\); the loops \(u\) was made through are its in-neighbours \(\operatorname{in}(u)\).
Definition 2 Release rules. A fault is a set \(S\) of loops that are dropped. Every loop can be dropped, including loops added by the barrier.
  • Downward rule (a ladder running towards the cast-on): a loop with at least one holder is released when all of its holders are released.
  • Upward rule (the mirror image): a loop made through at least one loop is released when all of the loops it was made through are released.
The closure \(\operatorname{cl}(S)\) is the smallest set that contains \(S\) and contains every loop the rule releases from it. The damage of \(S\) is \(|\operatorname{cl}(S)|\), and the worst case for \(k\) faults is \[ D_k \;=\; \max_{|S| \le k} \,|\operatorname{cl}(S)|. \]

The downward rule is the ladder: a loop stays in the fabric while any loop still holds it, and runs once every holder is gone. For the knit, split and tuck operations used here, it matches the drop and ladder rewrites of Hurtig et al. [2]: removing a knit exposes the loops it consumed, and a loop captured by several new loops (a split, then a knit) is exposed only when all of them have been removed. Loops of the working edge have no holder. They are released only when they are dropped themselves.

Lemma 1 Closure. For either rule, \(\operatorname{cl}(S)\) exists and is unique, and (a) \(S \subseteq \operatorname{cl}(S)\); (b) if \(S \subseteq T\) then \(\operatorname{cl}(S) \subseteq \operatorname{cl}(T)\); (c) \(\operatorname{cl}(\operatorname{cl}(S)) = \operatorname{cl}(S)\); (d) under the downward rule, \(\operatorname{cl}(S)\) is found in one pass over the loops from newest to oldest, adding each loop that is in \(S\) or whose holders are all already added. Under the upward rule, the pass runs from oldest to newest.
Proof. Call a set \(C\) closed if every loop whose holders are all in \(C\) (and that has at least one holder) is itself in \(C\). The whole set of loops is closed, and an intersection of closed sets is closed, so the intersection of all closed sets containing \(S\) is the smallest one: this is \(\operatorname{cl}(S)\). Then (a) is immediate. For (b), \(\operatorname{cl}(T)\) is closed and contains \(S\), so it contains \(\operatorname{cl}(S)\). For (c), \(\operatorname{cl}(S)\) is closed and contains itself. For (d), holders are newer than the loops they hold, so when the pass reaches a loop, the status of all its holders is final; the set produced is closed, contains \(S\), and each loop added is forced by the rule, so it equals \(\operatorname{cl}(S)\). The upward case is the same with the order reversed. ∎

Section 2

The barrier tube

The garment is a tube of \(W\) columns (stitches around), knitted on both beds of a V-bed machine at half gauge, so that column \(c+1\) is always the physical neighbour of column \(c\), including across both folds. Columns are numbered modulo \(W\). The program has \(m\) blocks \(b = 0, \dots, m-1\). Each block has \(s\) ordinary courses. Between two blocks sits one barrier course.

Definition 3 The loops.
  • Chain loops \(M_{b,c,l}\) for level \(l = 0,\dots,s-1\): the \(s\) loops of column \(c\) in block \(b\). Block 0 starts with a tuck cast-on.
  • Ports \(P_{b,c}\) for \(b \ge 1\): the barrier course before block \(b\) splits a new loop \(P_{b,c}\) through the top loop \(M_{b-1,c,s-1}\) of every column, keeps the old loop, and carries the port to column \(\sigma_b(c)\). For the fixed barrier, \(\sigma_b(c) = c + 1\).
The arrows (\(u \to v\): \(v\) is made through \(u\)): \[ \begin{aligned} &M_{b,c,l} \to M_{b,c,l+1} && \text{(ordinary course, } l < s-1)\\ &M_{b-1,c,s-1} \to M_{b,c,0} && \text{(the old loop, knitted through again)}\\ &M_{b-1,c,s-1} \to P_{b,c} \to M_{b,\sigma_b(c),0} && \text{(the port, knitted into the neighbour's first loop)} \end{aligned} \] Each map \(\sigma_b\) is a permutation of the columns, so every first loop \(M_{b,c,0}\) receives exactly one port. The tube has \(N = W\,(s\,m + m - 1)\) loops.

The barrier course is a course of \(W\) ordinary loops: the ports. Per course, the barrier tube knits as many loops as plain jersey. One block with its barrier course is \(s+1\) courses tall. The emitted program uses one yarn carrier and no cuts, and moves every port with its whole course in two racked transfer passes (section 11).

Section 3

Cells and rows

The proofs work on a coarser picture, where each block of each column is one cell.

Definition 4 Cells. Cell \((b,c)\) is the set of loops \[ L(b,c) \;=\; \{M_{b,c,0},\dots,M_{b,c,s-1}\} \;\cup\; \{P_{b,c'} : \sigma_b(c') = c\}, \] its chain and, for \(b \ge 1\), the one port knitted into it. The cells partition the loops. A cell has \(s+1\) loops, or \(s\) in block 0.
Definition 5 Row systems. Rows \(i = 0, 1, 2, \dots\) each hold \(W\) cells, and every row \(i\) has a map \(\tau_i\) of the columns. Cell \((i+1, c)\) is released when it is seeded, or when cells \((i, c)\) and \((i, \tau_i(c))\) are both released. Writing \(R_i\) for the released cells of row \(i\) and \(S_i\) for the seeds placed in it, \[ R_0 = S_0, \qquad R_{i+1} = E_i(R_i) \cup S_{i+1}, \qquad E_i(R) = \{c : c \in R \text{ and } \tau_i(c) \in R\}. \] \(E_i\) is the erosion of row \(i\). \(B_k\) denotes the largest total \(\sum_i |R_i|\) over all placements of at most \(k\) seeds. More generally, a support \(A\) replaces the pair \(\{c, \tau_i(c)\}\) by \(\{c + a : a \in A\}\).

The recursion computes the closure row by row, since a cell of row \(i+1\) depends only on row \(i\). Section 5 shows that the barrier tube, seen through its cells, is this row system with row \(i\) = block \(m-1-i\) and \(\tau_i = \sigma_{m-1-i}\): the working edge is row 0, and rows count down towards the cast-on.

Section 4 · the fabric

Theorem 1: a bound independent of garment size

Take the cyclic row system on \(W\) columns with support \(A = \{0, 1, \dots, r\}\) in every row, \(r \ge 1\). For the barrier tube, \(r = 1\). Define, for integers \(n\), \[ f_r(n) \;=\; \sum_{j \ge 0} \max(0,\, n - r j), \qquad\text{so}\qquad f_1(k) = \frac{k(k+1)}{2}. \] Two facts about \(f_r\) are used below, with \(f_r(n) = 0\) for \(n \le 0\): it is nondecreasing, and \(f_r(n) = n + f_r(n - r)\) for every \(n \ge 0\) (split off the \(j = 0\) term).

Lemma 2 Erosion of runs. Let \(W > r\) and let \(R\) be a set of \(n\) columns, \(R\) not the whole cycle. Then \(E(R) \subseteq R\) and \(|E(R)| \le \max(0,\, n - r)\). If \(R\) is one run of \(L\) consecutive columns, \(E(R)\) is one run of \(\max(0, L - r)\) columns.
Proof. \(0 \in A\), so every column of \(E(R)\) lies in \(R\). Since \(R\) is not the whole cycle, it splits into maximal runs of consecutive columns, each followed by a column outside \(R\). A column \(c\) is in \(E(R)\) exactly when \(c, c+1, \dots, c+r\) all lie in \(R\), that is, when \(c\) lies in a run of length \(L\) at distance at least \(r\) from the run's last column. A run of length \(L\) therefore contributes a run of \(\max(0, L-r)\) columns. If no run is longer than \(r\), \(E(R)\) is empty. Otherwise the runs longer than \(r\) contribute \(\sum (L_j - r) \le n - r\). ∎
Theorem 1 For every \(k\) and every \(W > \max(k, r)\), and every number of rows, \[ B_k \;\le\; f_r(k), \] with equality whenever there are at least \(\lceil k/r \rceil\) rows. For the barrier, \(B_k \le k(k+1)/2\), with equality from \(k\) rows.
Proof. No row fills up. Let \(n_i = |R_i|\) and \(t_i = |S_i|\). By Lemma 2, \(n_{i+1} \le n_i + t_{i+1}\), so \(n_i \le t_0 + \dots + t_i \le k < W\) for every \(i\). Every row is a proper subset, and Lemma 2 applies in every row: \[ n_{i+1} \;\le\; \max(0,\, n_i - r) + t_{i+1}. \tag{1}\] Induction. Let the rows be \(0, \dots, H\), and let \(T_i = t_{i+1} + \dots + t_H\) count the seeds placed below row \(i\). The claim is that for every \(i\), \[ \textstyle\sum_{j \ge i} n_j \;\le\; f_r(n_i + T_i). \tag{2}\] For \(i = H\), \(T_H = 0\) and \(n_H \le f_r(n_H)\). Assume (2) for \(i+1\). Since \(T_i = t_{i+1} + T_{i+1}\), inequality (1) gives \(n_{i+1} + T_{i+1} \le \max(0, n_i - r) + T_i\), and since \(f_r\) is nondecreasing, \[ \textstyle\sum_{j \ge i} n_j \;\le\; n_i + f_r\big(\max(0, n_i - r) + T_i\big). \] If \(n_i \ge r\), the right side is \(n_i + f_r(n_i + T_i - r) \le n_i + T_i + f_r(n_i + T_i - r) = f_r(n_i + T_i)\). If \(n_i < r\), it is \(n_i + f_r(T_i) = n_i + T_i + f_r(T_i - r) \le n_i + T_i + f_r(n_i + T_i - r) = f_r(n_i + T_i)\). This proves (2). At \(i = 0\), \(n_0 + T_0 = t_0 + \dots + t_H \le k\), so the total damage is at most \(f_r(k)\).
Attained. Seed \(k\) consecutive cells of row 0. By Lemma 2 the rows hold runs of \(k, k-r, k-2r, \dots\) cells, which sum to \(f_r(k)\) once there are \(\lceil k/r \rceil\) rows. ∎

Neither the bound nor its proof mentions \(W\) or the height, so the same limit holds for a 72-stitch cuff and a 320-stitch body. Sample tests cannot establish this, because the number of fault patterns grows with the garment (section 7).

Remark Any barrier whose port moves a fixed step \(a\) with \(\gcd(a, W) = 1\) has the same profile: relabelling column \(c\) as \(a^{-1} c \bmod W\) turns each pair \(\{c, c+a\}\) into \(\{c', c'+1\}\). Moving the port one column is enough.

Section 5 · the knitting program

Theorem 2: the bound survives compilation

The program has more loops than the cells of Theorem 1: \(s\) chain loops per cell and the ports. A fault can hit any of them. Two lemmas show that no such fault does more harm than a fault on a cell's top loop, and count the loops that cells release. Both hold for any permutations \(\sigma_b\), so they also cover the staggered barriers of section 10.

Lemma 3 Promotion. Map each loop to a top loop: \(\pi(M_{b,c,l}) = M_{b,c,s-1}\) and \(\pi(P_{b,c}) = M_{b,\sigma_b(c),s-1}\), the top of the cell the port belongs to. Under the downward rule, for every fault \(S\), \[ |\pi(S)| \le |S| \qquad\text{and}\qquad \operatorname{cl}(S) \subseteq \operatorname{cl}(\pi(S)). \]
Proof. The first claim holds because \(\pi\) is a map. For the second, it suffices by Lemma 1 to show \(S \subseteq \operatorname{cl}(\pi(S))\), since then \(\operatorname{cl}(S) \subseteq \operatorname{cl}(\operatorname{cl}(\pi(S))) = \operatorname{cl}(\pi(S))\). A chain loop \(M_{b,c,l}\) with \(l < s-1\) has one holder, \(M_{b,c,l+1}\); so once the top \(M_{b,c,s-1}\) is released, the whole chain down to \(M_{b,c,0}\) is released. A port \(P_{b,c}\) has one holder, \(M_{b,\sigma_b(c),0}\), the bottom of the chain of the cell it belongs to, so it is released with that chain. ∎
Lemma 4 Cells. Let \(Q\) be a set of top loops, let \(Q'\) be the corresponding cells, and let \(R\) be the closure of \(Q'\) in the row system with \(\tau_i = \sigma_{m-1-i}\). Then \[ \operatorname{cl}(Q) \;=\; \bigcup_{(b,c) \in R} L(b,c), \qquad |\operatorname{cl}(Q)| \;=\; (s+1)\,|R| \;-\; f_0, \] where \(f_0\) is the number of cells of \(R\) in block 0.
Proof. Write \(U\) for the union. \(U\) is closed and contains \(Q\). It contains \(Q\) because \(Q' \subseteq R\). Suppose a loop \(v \notin U\) has at least one holder and all its holders lie in \(U\). If \(v\) is a chain loop below the top, its only holder is the next loop of the same chain, whose cell is then in \(R\), so \(v \in U\). If \(v = P_{b,c}\), its only holder \(M_{b,\sigma_b(c),0}\) lies in \(U\), so cell \((b, \sigma_b(c))\) is in \(R\) and \(v\) belongs to it. If \(v = M_{b,c,s-1}\) with \(b < m-1\), its holders are \(M_{b+1,c,0}\) and \(P_{b+1,c}\); the first puts cell \((b+1, c)\) in \(R\), the second puts cell \((b+1, \sigma_{b+1}(c))\) in \(R\), so by the row rule \((b,c) \in R\) and \(v \in U\). Top loops of block \(m-1\) have no holder. Each case contradicts \(v \notin U\), so \(U\) is closed, and \(\operatorname{cl}(Q) \subseteq U\).
\(U \subseteq \operatorname{cl}(Q)\). By induction from block \(m-1\) down. A cell of \(R\) is either in \(Q'\), so its top is in \(Q\), or it has both supporting cells in the block above in \(R\), whose loops are released by induction; then both holders of its top are released, and so is the top. In both cases the top is released, and by the argument of Lemma 3 so are its chain and its port.
Count. The cells are disjoint. Each has \(s\) chain loops and, when \(b \ge 1\), exactly one port, because \(\sigma_b\) is a permutation. ∎
Theorem 2 For the fixed barrier, every \(W > k\) and every number of blocks, \[ D_k \;\le\; (s+1)\,\frac{k(k+1)}{2}, \] counting faults on every loop, chain loops and ports included. Equality holds when \(m \ge k+1\).
Proof. Take any fault \(S\) with \(|S| \le k\). By Lemma 3, \(|\operatorname{cl}(S)| \le |\operatorname{cl}(\pi(S))|\) with \(|\pi(S)| \le k\). By Lemma 4, \(|\operatorname{cl}(\pi(S))| \le (s+1)\,|R|\), where \(R\) is the closure of at most \(k\) cells in the row system with \(\tau_i(c) = c + 1\). By Theorem 1 with \(r = 1\), \(|R| \le k(k+1)/2\).
For equality, drop the top loops of \(k\) neighbouring columns in the newest block. The released cells are runs of \(k, k-1, \dots, 1\) cells in blocks \(m-1, \dots, m-k\) (Lemma 2). If \(m \ge k+1\), none lies in block 0, so \(f_0 = 0\) and Lemma 4 gives exactly \((s+1)\,k(k+1)/2\) loops. ∎
Remark With \(d\) holders per old loop (\(d - 1\) ports), the same two lemmas give \(D_k \le (s + d - 1)\,B_k\). The barrier here has \(d = 2\).

Section 6 · ladders running up

Theorem 3: ladders running up

A broken yarn can also run away from the cast-on. The upward rule of Definition 2 asks whether a loop can lose every loop it was made through.

Theorem 3 Under the upward rule, the barrier tube has the same worst case as under the downward rule: \(D_k \le (s+1)\,k(k+1)/2\) for every \(W > k\), with equality when \(m \ge k+1\).
Proof. Group the loops into upward cells \(U(b,c) = \{M_{b,c,0}, \dots, M_{b,c,s-1}\} \cup \{P_{b+1,c}\}\): the chain of column \(c\) in block \(b\) and the port split from its top (for \(b < m-1\)).
Promotion. A chain loop \(M_{b,c,l}\) with \(l \ge 1\) was made through one loop, \(M_{b,c,l-1}\); the port \(P_{b+1,c}\) was made through one loop, \(M_{b,c,s-1}\). So once the foot \(M_{b,c,0}\) is released, the whole upward cell is released, and a fault anywhere in \(U(b,c)\) is dominated by a fault at its foot, exactly as in Lemma 3.
Cells. For \(b \ge 1\), the foot \(M_{b,c,0}\) was made through two loops: \(M_{b-1,c,s-1} \in U(b-1, c)\) and the port \(P_{b,c'}\) with \(\sigma_b(c') = c\), which lies in \(U(b-1, c')\). The feet of block 0 are cast-on loops, made through nothing. The argument of Lemma 4 then shows that upward cells follow a row system with rows in the order \(b = 0, 1, \dots\) and \(\tau(c) = \sigma_b^{-1}(c) = c - 1\), and that the released loops number at most \((s+1)\) per cell.
The bound. The reflection \(c \mapsto -c\) turns the support \(\{0, -1\}\) into \(\{0, 1\}\), so Theorem 1 applies: at most \(k(k+1)/2\) cells, hence at most \((s+1)\,k(k+1)/2\) loops. Seeding the feet of \(k\) neighbouring columns in block 0 releases runs of \(k, k-1, \dots, 1\) upward cells in blocks \(0, \dots, k-1\); when \(m \ge k+1\) all of them lie below block \(m-1\) and have their port, giving equality. ∎

Section 7 · the sample sleeve

The 160-stitch sleeve

Corollary The sleeve has \(W = 160\), \(s = 8\), \(m = 13\): \(N = 160 \times (8 \times 13 + 12) = 18{,}560\) loops. For \(k\) dropped loops anywhere, in either direction, \[ D_k \;=\; 9\,\frac{k(k+1)}{2}: \qquad 9,\ 27,\ 54,\ 90,\ 135,\ 189,\ 252,\ 324,\ 405 \quad (k = 1, \dots, 9). \]
Proof. Theorems 2 and 3 with \(s = 8\); \(W = 160 > 9\) and \(m = 13 \ge 10\), so each value is attained. ∎

In centimetres. One dropped loop releases at most one cell: 8 chain loops of one column and one port, within one block of \(s + 1 = 9\) courses. At 9 courses per centimetre, that is about 1 cm. The centimetre figure depends on the gauge; the loop counts do not.

Plain knitting. In a plain tube each loop has one holder, the loop above it. One dropped loop at the top of a 116-course column releases all 116 loops of the column (Lemma 1d).

Fault patterns. The number of ways to choose 1 to 9 of the sleeve's 18,560 loops is \[ \sum_{k=1}^{9} \binom{18560}{k} \;=\; 719{,}129{,}210{,}529{,}640{,}888{,}003{,}430{,}838{,}628{,}432, \] a 33-digit number. Theorem 2 covers every one of these fault patterns.

Section 8 · opening on purpose

Theorem 4: opening the garment on purpose

Theorem 4 (a) Dropping the \(W\) top loops of the newest block releases every loop of the tube. (b) If fewer than \(W\) loops are dropped, every block keeps at least one column whose \(s\) chain loops are all unreleased. In particular, fewer than \(W\) faults never release the whole tube.
Proof. (a) In the row system, a full row erodes to a full row, so seeding all of row 0 releases every cell. Every loop belongs to a cell (Definition 4), so Lemma 4 gives every loop.
(b) Let \(|S| < W\). By Lemma 3, \(\operatorname{cl}(S) \subseteq \operatorname{cl}(\pi(S))\) with \(|\pi(S)| < W\), and by the first step of the proof of Theorem 1, each row of the closure \(R\) of \(\pi(S)\) holds fewer than \(W\) cells. So each block has a cell \((b,c) \notin R\), and by Lemma 4 no loop of \(L(b,c)\) is released. ∎

For the sleeve: dropping all 160 working-edge loops opens all 18,560 loops, while any 159 dropped loops leave at least \(8 \times 13 = 104\) loops in place. The program uses a single yarn carrier with no cuts, so the opened tube is one continuous yarn.

Section 9 · flat panels

Theorem 5: flat panels need one port cycle

A flat panel has no wrap-around. Its barrier carries the port of column \(c\) to column \(\sigma(c)\) for a permutation \(\sigma\) of the \(W\) columns.

Theorem 5 The following are equivalent: (i) for every \(k < W\), the worst case of \(k\) faults is bounded independently of the panel's height; (ii) no nonempty proper set of columns \(X\) satisfies \(\sigma(X) \subseteq X\); (iii) \(\sigma\) is a single cycle through all \(W\) columns. When they hold, the panel has exactly the tube's profile: \(D_k \le (s+1)\,k(k+1)/2\), with equality when \(m \ge k+1\).
Proof. (iii) ⇒ (i): number the columns along the cycle, \(c_j = \sigma^j(c_0)\). Then \(\sigma(c_j) = c_{j+1 \bmod W}\), and the panel's row system is the cyclic system with support \(\{0,1\}\); Theorems 1 to 3 apply unchanged. (i) ⇒ (ii): if \(\sigma(X) \subseteq X\) with \(X\) nonempty and proper, then \(\sigma(X) = X\) because \(\sigma\) is injective, so \(E(X) = X\). Dropping the top loops of the \(|X| < W\) columns of \(X\) releases the cells of \(X\) in every block, and the damage grows with the height. (ii) ⇒ (iii): the columns of any cycle of \(\sigma\) form a set \(X\) with \(\sigma(X) = X\), so under (ii) that cycle contains every column. ∎

No single cycle through all columns of a line uses only steps of one column. The zig-zag cycle \(0 \to 2 \to 4 \to \cdots\), then back down the odd columns to 1 and to 0, uses steps of at most two columns. Cutting the tube's pattern at the edge leaves the last column without a second holder, so one dropped loop runs its full height. Reflecting the last port inward makes the last two columns an invariant pair, so two dropped loops run the full height.

Section 10 · staggered barriers

Theorem 6: staggered barriers

With a fixed step, every two-holder barrier has the profile \(k(k+1)/2\). Alternating the step between barrier courses breaks this triangle: a run of released cells that shrinks slowly under one step shrinks fast under the other. The Studio uses the patterns \((a_1, a_2) = (2, 1)\) and \((3, 2)\), repeated. Let \(A\) be the largest step. The row system has \(\tau_i(c) = c + a_i\) with the steps repeating, and an attack may start at any phase of the pattern.

Lemma 5 Every released cell lies in a column that contains a seed.
Proof. An unseeded released cell \((i+1, c)\) needs \((i, c)\) released: each support contains the cell's own column. Going up the column, some released cell of column \(c\) is a seed. ∎
Lemma 6 Independent components. Join two seeded columns \(x, y\) when \(y - x\) is \(\pm\) a step (modulo \(W\) on a tube). Then the closure of the attack is the disjoint union of the closures of its connected components, each taken alone.
Proof. For a component \(K\), let \(S_K\) be its seeds. By Lemma 5, \(\operatorname{cl}(S_K)\) lies in the columns of \(K\), so these closures are disjoint, and each lies in \(\operatorname{cl}(S)\) by Lemma 1b. Their union \(U\) is closed: if \((i+1, c)\) has both supports \((i, c)\) and \((i, c + a_i)\) in \(U\), both columns are seeded and adjacent, hence in one component \(K\), and both cells are in \(\operatorname{cl}(S_K)\), so \((i+1, c) \in \operatorname{cl}(S_K)\). As \(U\) is closed and contains \(S\), \(\operatorname{cl}(S) \subseteq U\). ∎
Lemma 7 Lifting to the line. On a tube with \(W > A\,k\), a component with \(j \le k\) seeded columns behaves exactly as an attack on the infinite line \(\mathbb{Z}\) whose seeded columns lie in a window of \(A(j-1)+1\) columns.
Proof. Take a spanning tree of the component and lift its columns to integers along the tree: each tree edge changes the lift by the step it uses, at most \(A\). The intervals spanned by the tree edges form a connected union, so all lifts lie in an interval of length at most \(A(j-1)\). For two columns \(x, y\) of the component and a step \(a\), \(|\lambda(y) - \lambda(x) - a| \le A(j-1) + A \le A\,k < W\); hence \(y \equiv x + a \pmod W\) holds exactly when \(\lambda(y) = \lambda(x) + a\). Every support relation among the component's columns is the same on the tube and on the line, and cells outside seeded columns never release in either (Lemma 5), so the two closures correspond cell for cell. A finite tube only removes rows below its cast-on, which feed nothing above them. ∎
Theorem 6 Let \(\mathrm{Wn}(j)\) be the exact worst case of at most \(j\) seeds placed in a window of \(A(j-1)+1\) consecutive columns of the line, over every starting phase and every height. For every tube with \(W > A\,k\), \[ B_k \;\le\; \max_{k_1 + k_2 + \cdots = k} \;\sum_{t} \mathrm{Wn}(k_t), \] and the knitting program releases at most \((s+1)\) times this many loops, in either direction.
Proof. Split any attack of \(k\) seeds into components (Lemma 6), with \(k_t\) seeds in component \(t\), so \(\sum k_t \le k\). A component has at most \(k_t\) columns, so by Lemma 7 its damage is at most \(\mathrm{Wn}(k_t)\). Lemmas 3 and 4 hold for any permutations \(\sigma_b\), which gives the factor \(s+1\). For ladders running up, the proof of Theorem 3 applies with \(\tau(c) = c - a_b\), the steps met in increasing block order. Reflecting the columns, \(c \mapsto -c\), turns this into the downward system with the steps met in the opposite order. For a pattern of period 2 that is the same pattern at another phase, and \(\mathrm{Wn}\) is a maximum over every phase. ∎

The exact computation. \(\mathrm{Wn}(j)\) is a finite quantity: a longest-path dynamic program over the released set of the current row (at most \(2^{A(j-1)+1}\) states), the seeds left and the phase, with one move per added seed or eroded row. For \(j = 9\) and \(A = 3\) the window has 25 columns and 33.5 million states per phase. The program checks itself against Theorem 1 for a fixed step and reconstructs an attack that attains each value.

The attaining attacks release exactly \(9 B_k\) loops on the compiled programs of 32, 72 and 160 stitches (steps 3, 2 for every \(k \le 9\); steps 2, 1 upward for \(k \le 5\)), and on the 160-stitch construction for every \(k \le 9\) and both patterns (section 12). Section 11 · counted on the programs

Machine cost

The cost figures are counts on the emitted programs. A carriage pass is a maximal run of one operation class at one rack; loop-making passes also need one direction and monotone needles, and transfer passes need one source bed and no repeated needle.

A plain tube needs 2 passes per course. The split course takes the 2 passes of the knitted course it replaces. Each barrier then adds the transfers that carry the ports: 2 racked transfer passes, 2 single transfers around the folds and 2 return passes, 6 passes in all, independent of the circumference. At equal loop count (\(s\,m + m - 1\) courses), \[ \frac{\text{barrier passes}}{\text{plain passes}} \;=\; 1 + \frac{3\,(m-1)}{(s+1)\,m - 1} \;\xrightarrow[m \to \infty]{}\; 1 + \frac{3}{s+1}. \] For the sleeve (\(s = 8\), \(m = 13\)) this is \(1 + 36/116 = 1.31\). The staggered programs count 1.47 (steps 2, 1) and 1.62 (steps 3, 2). The first optimal designs of this project, which routed ports across the needle bed, counted 23,434 passes against 151 for plain knitting of the same loops: 155 times.

    Section 13 · what the theorems cover

    Scope

    • Covered: loop release in the declared model of section 1, in both directions, for the emitted tube, flat panel and staggered programs, with faults on any loop, including every loop the barrier adds.
    • Left out by the model: friction and yarn tension, fabric geometry and stretch, cut yarn and the motion of its free ends, washing and wear. Whether a physical ladder obeys the release rule at the barrier is the first question for physical tests.
    • Left out by the program: a wearable finish of the working edge. In the programs the top loops stay on the needles.
    • Centimetres are converted from the gauge: 9 courses per cm, the Studio's fine-knit default.
    • Next: knit barrier and plain samples, and measure ladder length after snagging, washing and wear against the bounds above.
